# Riset — Realokasi Anggaran MBG Rp180 Triliun (Simulasi 2027)

- **Status:** bahan riset dari pengguna, dirapikan dan diverifikasi aritmetikanya.
- **Sifat:** simulasi kebijakan. **Bukan** rencana pemerintah, **bukan** proyeksi resmi.
- **Tanggal kompilasi:** 25 November 2026.

---

## 1. Premis

| Parameter | Nilai |
| --- | --- |
| Periode | 1 tahun (2027) |
| Anggaran MBG awal | Rp240 triliun |
| MBG setelah pemangkasan | Rp60 triliun |
| Dana realokasi | **Rp180 triliun** |
| Prioritas | Daerah dengan kekurangan layanan |
| Orientasi | Manfaat langsung bagi masyarakat |

Aritmetika premis: `240 − 60 = 180` triliun. Bagian yang dipangkas = `180 / 240 = 75%`,
bukan separuh. Kalimat "separuh anggaran" **tidak boleh** dipakai.

### 1a. Kerangka final video (v3)

Video 60 detik memakai pembagian **rata**: Rp180 T ÷ 4 = **Rp45 T per bidang**
(infrastruktur, kesehatan, layanan publik, pendidikan & perumahan). Ini bukan
empat paket yang dijumlahkan.

Agar konsisten dengan biaya satuan di §3–§6, anggaran tiap program pada skenario
180 T diskalakan **1/4**, dan hasil km/unit ikut diskalakan 1/4. Dengan begitu
total tiap bidang tetap Rp45 T.

| Bidang | Program | Anggaran §3–§6 | Skala 1/4 | Hasil |
| --- | --- | --- | --- | --- |
| Infrastruktur | Jalan | Rp80 T → 14.388 km | Rp20 T | ±3.600 km |
| Infrastruktur | Rel | Rp50 T → 850 km | Rp12,5 T | ±210 km |
| Kesehatan | RSUD | Rp35 T → 205 RS | Rp8,75 T | ±51 RS |
| Kesehatan | Puskesmas | Rp25 T → 18.744 paket | Rp6,25 T | ±4.700 paket |
| Kesehatan | BPJS PBI | Rp70 T → 138,9 juta | Rp17,5 T | ±35 juta orang |
| Layanan publik | BRT | Rp40 T → 348 km | Rp10 T | ±87 km |
| Layanan publik | Bus | Rp10 T → 7.893 unit | Rp2,5 T | ±1.970 bus |
| Pendidikan | Sekolah | Rp50 T → 30.437 | Rp12,5 T | ±7.600 sekolah |
| Perumahan | BSPS | Rp60 T → 3.000.000 | Rp15 T | 750 ribu rumah |
| Perumahan | Rumah baru | Rp40 T → 800.000 | Rp10 T | 200 ribu rumah |

Angka-angka ini tetap **target simulasi / ekuivalen biaya**, bukan output fisik
2027. Aturan di §2 dan §8 tetap berlaku.

## 2. Tiga jenis angka

Ini pembeda yang harus dijaga di seluruh video dan dokumen lain.

| Jenis | Definisi | Contoh |
| --- | --- | --- |
| **Biaya pembanding** | Biaya proyek yang benar-benar pernah dikerjakan pemerintah | RSUD Buton Tengah Rp170 miliar; IJD Rp5,56 miliar/km |
| **Target simulasi** | Jumlah yang secara matematis dapat dibiayai dengan biaya pembanding itu | Rp35 T ÷ Rp170 M = 205 RS |
| **Target realisasi** | Jumlah yang realistis dikerjakan dalam satu tahun | 40 RS baru + 80 peningkatan + 85 alkes |

Video hanya boleh menyebut **target simulasi** dengan kata "setara biaya" atau
"ekuivalen", bukan "akan dibangun".

## 3. Skenario 1 — Infrastruktur nasional

| Program | Anggaran |
| --- | --- |
| Jalan nasional dan daerah | Rp80 T |
| Jalur kereta api | Rp50 T |
| Jembatan dan konektivitas terpencil | Rp30 T |
| Pembebasan lahan, desain, persiapan | Rp20 T |
| **Total** | **Rp180 T** |

**Jalan.** Pembanding: Inpres Jalan Daerah 2025–2026 menangani 1.923 km dengan
Rp10,7 T (termasuk pengawasan).

```
10.700 miliar ÷ 1.923 km = 5,564 miliar/km
80.000 miliar ÷ 5,564     = 14.388 km
```

Komposisi indikatif: 8.000 km rekonstruksi/peningkatan, 6.388 km rehabilitasi.
Ini asumsi perencanaan, bukan hasil kontrak.

**Rel.** Pembanding: Makassar–Parepare 157,7 km, investasi Rp9,28 T.

```
9.280 miliar ÷ 157,7 km = 58,85 miliar/km
50.000 miliar ÷ 58,85   = 850 km
```

850 km adalah **ekuivalen pembiayaan**, bukan panjang rel yang selesai 2027.

**Konteks kebutuhan.** BPS 2024: ±142.548 km jalan kabupaten/kota rusak berat.
Sepuluh provinsi terbesar: Sumatera Utara, NTT, Sulawesi Selatan, Aceh,
Kalimantan Tengah, Sulawesi Tengah, Sumatera Barat, Sulawesi Tenggara, Riau, Jambi.

## 4. Skenario 2 — Kesehatan masyarakat

| Program | Anggaran |
| --- | --- |
| Pembangunan dan peningkatan RSUD | Rp35 T |
| Pembangunan dan peningkatan Puskesmas | Rp25 T |
| Subsidi BPJS bagi masyarakat rentan | Rp70 T |
| Obat, alat kesehatan, ambulans | Rp25 T |
| Tenaga medis dan layanan daerah terpencil | Rp25 T |
| **Total** | **Rp180 T** |

**Rumah sakit.** Pembanding: RSUD Buton Tengah tipe C, Rp170 miliar.

```
35.000 miliar ÷ 170 = 205 unit setara biaya
```

Komposisi operasional yang disarankan: 40 RS baru, 80 peningkatan RSUD,
85 peningkatan alkes dan layanan. Tiga jenis intervensi itu **tidak** berbiaya sama.

**Puskesmas.** Pembanding: DAK Fisik 2025, Rp2,34 T untuk 1.754 Puskesmas.

```
2.340 miliar ÷ 1.754 = 1,334 miliar/paket
25.000 ÷ 1,334       = 18.744 paket
```

**BPJS.** Iuran PBI Rp42.000/orang/bulan = Rp504.000/orang/tahun.

```
70.000.000 juta ÷ 504.000 = 138,9 juta orang-tahun
```

Ini kapasitas pembiayaan, **bukan** 138,9 juta penerima baru. Penerima aktual
harus dikurangi peserta PBI yang sudah dibiayai APBN.

**Kesenjangan.** Rasio tempat tidur nasional 1,4 per 1.000 penduduk; Papua
Pegunungan 0,4; Papua Tengah 0,7 (Profil Kesehatan Indonesia 2023).

## 5. Skenario 3 — Pelayanan publik dan transportasi

| Program | Anggaran |
| --- | --- |
| Pembangunan koridor BRT | Rp40 T |
| Pengadaan armada bus | Rp10 T |
| Subsidi tiket dan operasional | Rp60 T |
| Trotoar dan jalur sepeda | Rp25 T |
| Taman kota dan RTH | Rp25 T |
| Perpustakaan, olahraga, ruang publik | Rp20 T |
| **Total** | **Rp180 T** |

**BRT.** Pembanding: Trans Semarang, 17,4 km, estimasi Rp2 T.

```
2.000 miliar ÷ 17,4 km = 114,9 miliar/km
40.000 ÷ 114,9         = 348 km
```

**Bus.** Pembanding: DAMRI 2024, bus medium Rp1,267 miliar/unit.

```
10.000 ÷ 1,267 = 7.893 unit
```

Belum termasuk depo dan biaya operasional.

## 6. Skenario 4 — Pendidikan dan perumahan

| Program | Anggaran |
| --- | --- |
| Renovasi dan pembangunan sekolah | Rp50 T |
| Perbaikan rumah tidak layak huni | Rp60 T |
| Bantuan pembangunan rumah baru | Rp40 T |
| Beasiswa dan bantuan pendidikan | Rp20 T |
| Sanitasi dan infrastruktur permukiman | Rp10 T |
| **Total** | **Rp180 T** |

**Sekolah.** Pembanding: revitalisasi 2025, Rp17,15 T untuk 10.440 satuan pendidikan.

```
17.150 miliar ÷ 10.440 = 1,643 miliar/satuan
50.000 ÷ 1,643         = 30.437 satuan
```

**Rumah tidak layak huni.** BSPS Rp20 juta/unit (Papua dan Maluku Utara Rp25–40 juta).

```
60.000.000 juta ÷ 20 juta = 3.000.000 unit
```

**Rumah baru.** Asumsi bantuan pemerintah Rp50 juta/unit, bukan biaya total.

```
40.000.000 juta ÷ 50 juta = 800.000 unit
```

## 8. Yang tidak boleh diklaim

1. **Empat skenario bukan empat paket.** Totalnya bukan Rp720 T; masing-masing
   alternatif yang menyerap seluruh Rp180 T.
2. **Target simulasi ≠ output fisik 2027.** Sebagian besar proyek butuh
   multiyears, lahan, dan tender.
3. **Penerima manfaat tidak boleh dijumlahkan.** 138,9 juta orang-tahun bukan
   penerima baru; 18.744 paket Puskesmas bukan 18.744 gedung.
4. **Biaya pemeliharaan belum masuk.** Jalan, RS, bus, dan taman butuh biaya
   operasional setelah dibangun.
5. **Tidak ada daftar ruas atau kabupaten yang terverifikasi.** Distribusi
   provinsi di dokumen riset bersifat indikatif dan proporsional.
6. **Bukan rencana pemerintah.** Seluruhnya simulasi.
